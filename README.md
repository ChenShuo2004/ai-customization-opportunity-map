# AI 定制机会地图

中国大陆 AI 媒体定制的交互式研究网页。013 版按 **20 个市场 → 101 个研究类目 → 569 个具体商品** 浏览；类目是研究单元，最终经营方向可以组合多个类目。

## 本地查看

在本目录运行 `python3 -m http.server 8766`，打开 `http://localhost:8766`。纯静态 HTML、CSS、JavaScript，无构建步骤。

## 当前能说明什么

- 013 已完成层级对账，101 个类目全部在同一研究池。10 类“优先补证”、10 类“并行观察”、81 类“全量待查”仅代表研究顺序。
- 八项类目实证评分、市场规模、头部成交额与团队利润尚未核实，因此正式类目象限目前全部未定位。013 的 10 条公开资料是线索和反证，不是 10 笔订单。
- 012 商品级的 249 项资格初筛、15 项观察池、5 项四天待测方案保留作商品层材料。51 项旧多轴预评只是历史展示样本，不是正式排名母池。
- “商品初判”页沿用 012 的三张规则图，可查看 V0 和 010 历史假设；图中的高低不能代替成交、获客或利润实测。

## 数据更新

`category-013-data.js` 由 `research-data/build-013.py` 从用户交付的 013 ZIP 生成。原始 ZIP 内容留在本地 `research-data/batch-013/`，不发布。类目证据原始记录填写在本地 `research-data/类目证据记录.csv`，只有标明“公开展示=是”的行会进入公开页面的 `category-observations.js`。私有买家信息和订单流水不要写入公开行。

正式类目象限至少需要 **6/8 项有可追溯评分**，且“实际成交、获客可达、单位经济性”和当前选中的两轴均已核实。每项还需原始观测、统计周期、来源、核验日期、评分规则 ID 与复核人。`category-rubrics.js` 目前没有批准的评分规则，因 0–5 分的可复现阈值尚待制定；当前填写的分数不会自动进入正式象限。
